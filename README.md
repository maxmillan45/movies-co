## Movies-co 

---

## How the Application Works

1. Movie data is stored in an array of objects.

2. The **MovieList component** dynamically renders the movies using the `.map()` function.

3. Each movie is displayed through the **MovieItem component**.

4. Users can:
   - Add a new movie using the input field
   - Delete a movie using the delete button

React state (`useState`) updates the UI automatically.
